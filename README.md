# Novakid referral page — prototype (v3)

Interactive prototype of the redesigned parent referral page (NPA-9307), built to
match the final Figma and styled entirely on the Novakid Design System tokens
(`@diyoriko/nk-tokens`, vendored as `nk-tokens.css`).

**Live:** https://diyoriko.github.io/novakid-referral-preview/

Static HTML/CSS/JS. The share buttons hand out this page's own URL, which carries an
absolute Open Graph card (`assets/og-card.png`, 1200×630), so links shared to
WhatsApp / Telegram / Facebook unfurl with the preview. Placeholder data only.
